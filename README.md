# Cyber Otimizador do Sistema — by F-18

Ferramenta portátil de limpeza e otimização do Windows, num único ficheiro.

## Funcionalidades
- Limpeza profunda: ficheiros temporários, cache, prefetch, componentes do Windows (DISM), com Modo Rápido e Modo Profundo
- Remoção de aplicações desnecessárias e telemetria (reversível)
- Temperaturas em tempo real (CPU, GPU e placa-mãe) com motor de sensores integrado
- Utilização de CPU, memória e rede em tempo real
- Gestão de processos e teste de latência, com menu de ações
- Modo NITRO (alto desempenho temporário)
- Ferramentas: gestor de arranque, desinstalador, verificação de estado, reposição de rede, reiniciar o Explorador e agendamento de limpeza automática
- Atualizações automáticas a partir deste repositório

## Como usar
Transfere o `CyberOtimizador.bat` e faz duplo clique. O programa pede permissões de administrador e abre a interface.

## Criar versão .exe (opcional, com ícone)
Executa o `CRIAR_EXE.bat` no Windows (na primeira vez precisa de ligação à internet). Gera o `CyberOtimizador.exe`, um único ficheiro já com ícone.

## Atualizações
O programa consulta o `version.json` deste repositório. Quando existe uma versão nova, aparece um aviso dentro do programa com as novidades.
