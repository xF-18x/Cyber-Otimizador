# Cyber Otimizador do Sistema — by F-18

Ferramenta portátil de limpeza e otimização do Windows, num único ficheiro.

## Funcionalidades
- Limpeza profunda (temporários, cache, prefetch, DISM, etc.) — Modo Rápido e Modo Profundo
- Remoção de bloatware e telemetria (reversível)
- Temperaturas ao vivo (CPU / GPU / Placa) com motor de sensores embutido
- Uso de CPU / RAM / Rede em tempo real
- Gestão de **Processos** e teste de **Latência** com menu de ações
- Boost **NITRO** (alto desempenho temporário)
- **Ferramentas**: gestor de arranque, desinstalador, verificação de saúde, repor rede, reiniciar Explorador, agendar limpeza automática
- Minimiza para a bandeja com a temperatura do CPU
- **Atualizações automáticas** através deste repositório

## Como usar
Descarrega o `CyberOtimizador.bat` e faz duplo-clique. Ele pede permissões de Administrador e abre a interface.

## Criar versão .exe (opcional, com ícone)
Corre o `CRIAR_EXE.bat` no Windows (precisa de Internet à primeira vez). Gera `CyberOtimizador.exe`, ficheiro único com ícone.

## Atualizações
O programa consulta o `version.json` deste repositório. Quando sai uma versão nova, aparece um aviso dentro do programa.
